# 02 · 架构与技术选型

> 状态：M0 已落地骨架（2026-10-18）。本文档只记录**实际存在**的结构；未实现的能力在 `plan/05` 里列 ⬜。

## 一、形态与硬约束

| 项 | 决定 | 落地方式 |
| --- | --- | --- |
| 交付形态 | 纯前端单页 Web 游戏 | `index.html` + `src/`，`npm run build` 产出 `dist/index.html` |
| 后端 | 无 | 每日题 = 日期字符串 → FNV-1a → xorshift128+ |
| 框架 | 无 | 原生 ESM + Canvas2D |
| 第三方依赖 | 零（dev 也零） | `package.json` 的 `dependencies` / `devDependencies` 均为空 |
| 外链 | 零 | 构建产物静态扫描 `http(s)://` 计数必须为 0；字体用系统 `ui-monospace` 栈 |
| 美术资源 | 无位图 | 门与走线用 Canvas 几何图形绘制 |
| 数据 | 无外部数据集 | 关卡与 fixture 全部程序化生成 |
| 隐私 | 零上传 / 零遥测 | 不引统计脚本；页面唯一请求是文档自身 |

## 二、分层

```
index.html                 页面骨架 + 内联样式 + 面板 DOM
src/core/rng.mjs           xorshift128+ / FNV-1a / 归一化 seed
src/core/netlist.mjs       网表校验、拓扑排序、关卡 JSON 序列化
src/core/sim.mjs           三值 unit-delay 仿真核、真值表、首个失配
src/core/solver.mjs        门数成本表（公式复杂度 DP）、输出锥计数
src/core/generator.mjs     seed → 网表 → 求解器复核 → 关卡
src/core/replay.mjs        短码编解码（版本 + seed + 探测 + 网表 + CRC16）
src/ui/render.mjs          Canvas2D 绘制（只消费 sim 输出，零判定）
src/ui/app.mjs             交互：拨杆 → 仿真 → 灯、探测计数、关卡切换
src/ui/level-source.mjs    seed 解析（URL hash / 日期）
tools/build.mjs            单文件构建（内联模块，零外链断言）
tools/bundle.mjs           依赖序拼接（无打包器依赖）
tools/serve.mjs            本地回环静态服务器
tools/verify.mjs           一条命令全量自检
tools/gen-fixtures.mjs     1000 条随机网表 fixture（--check 字节级复核）
tools/replay-child.mjs     跨进程回放子进程
tests/                     node:test 用例 + 独立第二实现
```

**依赖方向**：`ui → core`，`tools → core`（构建除外），`tests/reference →` 不 import 生产模块。`core` 不 import `ui`/`tools`，也不读 DOM、时钟、随机数。

## 三、构建

- 自写 `tools/bundle.mjs`：按相对 import 深度优先排序，剥掉 `import ... from` 与 `export` 关键字，拼成一个 `<script type="module">`。
- **不引入打包器**：零依赖是隐私与体积承诺的一部分（D5），也避免锁文件与供应链面。
- 构建产物**确定性**：文件顺序固定、无时间戳、无 sourcemap；两次构建逐字节一致（`tests/build.test.mjs` 断言）。
- 体积：M0 骨架实测 38,317 字节 / gzip 13,337 字节，远低于 150KB gzip 目标；末态回填 `docs/verify-sample.txt`。
- `dist/` 入 `.gitignore`，不进仓库；发布期由 M6 作为 Release 附件承载（D13）。

## 四、运行期确定性

| 风险 | 约束 |
| --- | --- |
| 随机性 | 只有 `rng.mjs` 产生随机流；`Math.random` 在 `src/` 中零出现 |
| 时间 | `src/core` 不读 `Date`/`performance.now`；UI 只在"今日题"按钮读一次本地日期 |
| 对象键序 | 关卡 JSON 走 `levelToJson` 的显式字段顺序；遍历输出端口一律用数组顺序 |
| 区域设置 | 不用 `Intl`、`toLocaleString`、本地化数字格式 |
| 浮点 | 仿真与求解全是整数/位运算；只有计时统计（verify 报告项）用浮点 |
| 浮点差异 | CANVAS 绘制可自由用浮点（只影响像素，不影响判定） |

## 五、失败路径

| 场景 | 行为 |
| --- | --- |
| 网表非法 | `simulate` 返回 `{ok:false, errors}`，不抛异常；UI 显示提示 |
| 组合环 | 环成员恒 X，诊断里点名，不挂死 |
| 未稳定 | 达到 `门数 + 1` tick 上限后按全 X 处理并记诊断 |
| seed 不可生成 | `generateLevel` 返回 `{ok:false, code:"level-generation-failed"}`，UI 提示换种子 |
| 短码损坏/版本不符 | `decodeRecord` 抛带原因的错（校验失败 / 版本不兼容），不错误回放 |
| 构建出现外链 | `build.mjs` 直接抛错，不写产物 |
| `verify --require` 未知项 | 报一条 FAIL，不静默全绿 |
