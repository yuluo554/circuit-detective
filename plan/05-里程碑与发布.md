## 八、CI 预置说明

`.github/workflows/ci.yml` 在 M0 落盘但**从未被真实执行**（无远端）。本地只做两件事：

1. 用 `node -e` 解析 YAML 并断言 job / step 数（防"纯量里含 `: ` 导致 0 job"）；
2. 在本机按 workflow 的每一步逐条手工复跑（`npm test`、`npm run verify`、`npm run build`）。

按 sprint 纪律：**M6 首推前不得在 DoD 里写"CI 绿"**，只能写"本地等价校验（未接远端，CI 待首推验证）"。

**本轮修掉的缺陷（都有复现或变异验证）**

1. **计分口径自相矛盾**（D21）：`countedGates` 按锥内去重时，10000 关里有 1 关出现"你的门数 < 求解器最优"，与 §4.4「差值 ≥ 0」冲突。
2. **相邻拼块抢点击**（D24）：端到端冒烟实测点 A 的输出却命中 B 的输入，导致连线漏接、提交被判未完成。
3. **恒等冗余门**（D22）：`AND(x,x)` / `OR(x,x)` 使"照答案拼装"仍得到差值 1。
4. **`undefined` 字面量埋在 `replay.mjs`**：M4 接短码 UI 时会让构建断言变红；已前移为 `tests/source-hygiene.test.mjs` 全域守卫。
